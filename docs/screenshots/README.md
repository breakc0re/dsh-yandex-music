# Скриншоты

PNG в этой папке отрендерены из настоящей таблицы стилей плагина
(\client.js\, блок \CSS\) и настоящих данных каталога станций из
\plugin-data/dsh-yandex-music/cache/stations.json\. Обложки и иконки — реальные
картинки Яндекс Музыки, подгруженные по ссылкам.

Пересобрать: \
ode build-previews.mjs\, затем \chrome --headless=new
--screenshot=... docs/screenshots/.preview/*.html\.
